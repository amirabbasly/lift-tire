# ممیزی اولیه فنی و سئو لیفت تایر — پیش از تغییرات این درخواست

تاریخ: ۱۱ نوامبر ۲۰۲۶. مبنا: شاخه `arena/89f0c5de-lift-tire` در commit `7c7475d` و بررسی فقط‌خواندنی صفحه اصلی، مجله، دسته سواری، robots و sitemap عمومی. هیچ تراکنش یا درخواست ایندکس روی سایت زنده انجام نشده است. نبودِ نتیجه در جست‌وجو، اثبات نبودِ ایندکس نیست؛ داده Search Console، رتبه، ترافیک، بک‌لینک رقبا، دسترسی میزبان و داده میدانی Core Web Vitals در دسترس نیست.

## معماری و وضعیت موجود

- فروشگاه: Next.js 15، React 19 و App Router در `frontend/app/(site)`؛ پنل مدیریت در `/admin`. فونت Vazir و Barlow به‌صورت localFont؛ تصاویر عمدتاً `<img>`، برخی lazy و بعضی eager؛ بهینه‌ساز Next Image غیرفعال است (`images.unoptimized`).
- API: Express، PostgreSQL در Docker و PGlite به‌عنوان گزینه توسعه/PM2. جدول‌های products، product_images، product_specs، categories، brands، posts، reviews، orders و settings موجودند. مشخصات خودرو یک متن آزاد است، نه جدول سازگاری تأییدشده.
- مسیرهای اصلی موجود: `/`، `/products`، `/products/[slug]`، `/category/[slug]`، `/blog`، `/blog/[slug]` و `/blog/category/[category]`، صفحات حساب، سبد، پرداخت و مدیریت. سیستم مستقل مجلهٔ دوم لازم نیست.
- مجله فعلی با محتوای CMS و محتوای فایل‌محور، دسته، صفحه‌بندی، نویسنده، تاریخ، تصویر، breadcrumb و مطالب مرتبط کار می‌کند. صفحه‌های تحریریه فایل‌محور از seed دیتابیس جدا هستند.
- SEO موجود: canonical، OG برای مقاله/محصول، `fa`/RTL، BlogPosting، BreadcrumbList، Organization، WebSite و Product/Offer بدون امتیاز ساختاریافته؛ sitemap محصولات از همه صفحه‌های API و مقالات را می‌خواند. `robots.txt` مدیریت/API را مسدود می‌کند؛ حساب، سبد، سفارش، تسویه و فیلترهای دلخواه `noindex` دارند.
- زیرساخت داخل مخزن: Docker Compose شامل PostgreSQL، API، وب و nginx؛ گزینه جداگانه PM2 در `ecosystem.config.cjs` و `scripts/deploy-pm2.sh`. اینکه سرور واقعی کدام را اجرا می‌کند تأیید نشده است. متغیرهای عمومی سایت و تأیید اختیاری Search Console در `.env.example` تعریف شده‌اند. GA4/GTM یا اتصال فعال Search Console در کد پیدا نشد؛ وضعیت مالکیت و ابزارهای نصب‌شده خارج از مخزن نامعلوم است.

## محدودیت‌های این ممیزی

تست عمیق حساب، تسویه، ایجاد سفارش یا تنظیمات تولید انجام نشده است. عدم مشاهده ابزار تحلیل در مخزن، اثبات نبود آن در CDN/سرور نیست. هیچ حجم جست‌وجو، سختی کلمه، رتبه رقیب، تعداد بک‌لینک یا بهبود سرعت تخمین زده نشده است. راهنمای SEO قبلی: `docs/seo-search-console.md`؛ مقایسهٔ مقدماتی: `docs/seo-competitor-review.md`.
